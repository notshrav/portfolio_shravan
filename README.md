# Shravan Mittal — Portfolio

A personal portfolio built with HTML, CSS and vanilla JavaScript.

## Projects

The projects section features JustOneThing, a Niramaya card crediting my design contribution, and individual cards for the rest of my public GitHub repositories. Cards update from GitHub when the page loads. Codeforces, VIT Lost & Found, and portfolio repositories are filtered out. Scroll over the project strip with a mouse wheel to move one project at a time; touch and trackpad users can swipe or scroll horizontally.

## Publish with GitHub Pages

1. Push these files to the main branch of `notshrav/portfolio_shravan`.
2. In the repository, open Settings → Pages and select GitHub Actions as the build and deployment source.
3. The included workflow deploys the static site after each push to main. Once it finishes, the Pages URL appears in Settings → Pages.

No build step or secret keys are required. If GitHub's public API is temporarily unavailable, the rest of the site remains available and the portfolio links directly to the profile.

## Personalize

- Change the GitHub account at the top of `script.js`.
- Update the introduction and contact details in `index.html`.
- Add project images to `assets/` and link them from the page.
